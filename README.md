This repository contains the complete codebase for the "Multiple Disease Prediction Streamlit App", which is designed to predict the likelihood of various diseases based on user inputs. The repository is structured in a way that makes it easy to navigate, with separate folders for the training notebooks and the datasets used to build and evaluate the models.

The core of the application is implemented in app.py, which leverages the Streamlit framework to provide an interactive and user-friendly web interface for making predictions. To get started with the app, simply install the required dependencies by running:

pip install -r requirements.txt


This will set up all the necessary Python libraries needed to launch the Streamlit app. In addition, the repository includes Jupyter notebooks that contain the training and experimentation code for building the underlying machine learning models. Depending on your environment, you may need to install a few extra libraries to execute these notebooks smoothly.

Overall, the repository not only allows you to run the disease prediction app but also gives you full access to the training workflow, datasets, and model development process, making it both a ready-to-use tool and a learning resource for exploring machine learning in healthcare.
